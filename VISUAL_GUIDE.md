## Command Flow

### One-Time Setup
```
Step 1: Create PostgreSQL Migrations
$ dotnet ef migrations add InitialCreate --context ApplicationDbContext
$ dotnet ef migrations add InitialCreate --context ReadOnlyDbContext

Step 2: Build Docker Images
$ docker-compose build

Step 3: Start Containers
$ docker-compose up

Step 4: Apply Migrations
$ docker-compose exec api dotnet ef database update --context ApplicationDbContext
$ docker-compose exec api dotnet ef database update --context ReadOnlyDbContext
```

### Subsequent Runs (You're Done With Setup!)
```
$ docker-compose up

That's it! Everything starts automatically.
```

## Data Flow: Event Processing

```
1. Client sends webhook event
   POST /api/cms/events
        ?
2. WebhookController receives request
   (in API container at localhost:5000)
        ?
3. EventProcessingService processes event
   (in API container memory)
        ?
4. Database is updated
   (via network to PostgreSQL container at database:5432)
        ?
5. Response sent to client
   202 Accepted
        ?
6. Entity data persists
   (in PostgreSQL volume on your machine)
```
